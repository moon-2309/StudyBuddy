StudyBuddy!

Your personal study partner, an user friendly web application that helps you plan out your study schedule and plan out focused sessions.

Features

Task Manager: Add, edit, delete and complete study tasks.

Weekly Planner: Organise study sessions throughout the week.

Focus Timer: Manage focused study sessions and breaks.

Progress Tracker: Track completed tasks and study progress.

Responsive Design: Use the website across different screen sizes.

Local Storage: Save tasks and study data in the browser.
